How it works

From install to payout

Setup

A command line and systemd

Ubuntu 22.04, an NVIDIA driver and Docker.

$ node/install.sh
$ source .venv/bin/activate
$ beetle host init --chain chain.json --public-addr IP:41710 --stun HOST:PORT
$ beetle host doctor
$ beetle host list --models qwen3.5-2b --train-usd-per-mtok 20 --infer-in 1 --infer-out 3 --vllm-serve qwen3.5-2b
$ sudo systemctl enable --now beetle-host
