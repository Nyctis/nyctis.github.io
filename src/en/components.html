What Beetle is made of

Each part below is listed with what it does and where its code lives.

Layers

Clientyour machinedaemon, CLI, local API, SDK, MCP, doctor, policy, proof card
Networkbetween two machinesiroh direct link, sealed channel, file transfer, rendezvous
Environmentthe seller's machinesandbox, recipe mode, evidence
Seller nodethe seller's machinehost daemon, plaintext process, inference gateway, metering
ChainSolanaBeetle program, payment channels

Money and addresses go through the chain. Content goes directly between two machines. Keys are created on the buyer's machine and inside the environment, and never pass through a service we run.

Client

Everything on the buyer's machine runs inside one local daemon. The CLI, SDK and MCP tools are its clients, so an agent never holds the wallet.

Network

Two layers of encryption run over one direct link. The outer layer ends at the host and handles transport. The inner layer ends inside the environment, so the wire only ever carries ciphertext.

ComponentWhat it doesCode
Direct linkBoth sides dial at once over iroh with relays off, and the first connection winsnet/peer.py
RendezvousExchanges sealed addresses through a chain account, or through memos when no account existsnet/rendezvous.py
Sealed channelHPKE to the environment's key, in fixed-size frames, with resume after a dropped linknet/channel.py
File transfer1 MiB chunks with SHA-256 checks and resume. Files are padded to fixed sizesnet/transfer.py
Address echoTells a peer the public address it was seen fromnet/echo.py

Environment

The workload container has no network interface. Only ciphertext and public model files go in or come out. What the machine's owner can read depends on the tier, and the evidence decides the tier.

ComponentWhat it doesCode
SandboxChecks that it has no network, creates one-time keys, verifies inputs and the model hash, trains, scores, signssandbox/enclave.py
Recipe modeA built-in memory recipe with baseline, training, hidden scoring and a regression checksandbox/train_eval.py
Evidence verifierChecks a seller's evidence on the buyer's own machineattester/verifier.py

Seller node

Linux sellers use a command line and systemd. The daemon holds the wallet and moves ciphertext. The process that sees inference plaintext runs separately and does not read the wallet.

Chain

Beetle is one Anchor program on Solana, plus the Solana Foundation's payment channels. It settles in USDC and has no token. The program does not judge evidence or quality. It moves money only on objective facts.

ComponentWhat it doesCode

Crypto wrappersHPKE, AES-GCM, Ed25519, padding and hashing. These wrap established librariescommon/beetle_crypto.py
